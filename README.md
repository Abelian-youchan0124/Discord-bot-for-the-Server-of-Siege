# Discord-bot-for-the-Server-of-Siege

## 「シージ民の住処」用自作botファイル置き場

### 「シージ民の住処」のサーバ管理自動化用の自作botファイル置き場です
    - このリポジトリを閲覧できるのは、今のところサーバ運営陣に限っています。一般に公開するかは様子を見て考えます。
    - 一般ユーザに閲覧やcloneなどを行う許可を出したい場合は「BOT管理者」に許可を得てください。
    - 今のところ、特段の事情がない限り一般ユーザの閲覧やclone、ブランチ作成等はできません。
    - まずご自身のニックネームをつけたフォルダを作成してください。
    - ご自身のフォルダ内にbot毎のフォルダを作成し、フォルダ名はbot名にしてください。bot名が未定の場合は適当に命名し、フォルダ名の最後に「（仮）」等とつけ、正式名称が決まったらリネームして「（仮）」を外してください。
    - botやご自身のフォルダ内のフォルダの命名規則は特に設けませんが、必ずフォルダ内に「ReadMe」ファイル（.mdまたは.txt形式のもの）を作成し、機能と操作方法、注意事項が分かるように作成の上、最後に作成者のdiscordネームを書いておいてください。
    - botコマンドを設定する際、「#」「!」「/」でコマンドを始めるbotがとても多いので、できれば別の記号を使うようにして頂けると、無関係なbotの誤応答を防止できます。
    - リポジトリ内のbotを一部他サーバに合わせて書き換えた上で他サーバで使いたい場合は、作成者の許可を得てからにしてください。共同作成botの場合は作成者全員の許可を得てください。
    - ファイルの修正や改造は、自分用のブランチを作成して、そこで行うようにしてください。ブランチには自分のdiscordネームをつけ、誰のブランチか分かるようにお願いします。レビューやテストを経て完成したものはメインブランチにpullします。
    - 一人で複数のブランチを作る場合、「○○○○（ユーザ名）-001」のように、3桁の数（第1ブランチは001、以後1ずつ昇順）でのナンバリングをお願いします。
    - 改変したものはすぐにpullせず、一旦自ブランチでcommitし、commitコメントに改変箇所と内容を書き、commitした旨を作成者に報告してください。
    - BOT管理人および作成者に周知せず、唐突にpull requestしないでください。
    - 既存botの改良などは、一言作成者に声がけしてから行うようにしてください
    - サーバの為に自作した、あるいは自作途中のbotがあれば、自フォルダ内に新しくフォルダを作ってどんどんupお願いします。
    - 誰かにレビューを求められたらできるだけ快く引き受けましょう。
    -　Gitの使い方が分からない、Gitを初めて使う方は、 https://git-tutorial.backlog.com/  に分かりやすいgitの説明や使い方が記載されているので、一度読んでみてください。
    -　上記のサイトを読んでも分からないことがあれば、BOT管理人にロールメンションの上、運営会議chにてご質問ください。
